# Skills Matrix — SOC Analyst Track

Use this matrix to show current progress honestly. A topic being on this roadmap does not mean it is already a mastered skill. Add links to specific evidence when available.

## Status Definitions

- **Not yet assessed** — not yet studied or evaluated through practice.
- **Learning** — currently studying the topic.
- **Practiced in a lab** — completed an exercise in an authorized training environment.
- **Demonstrated in a project** — completed and documented a project with evidence.
- **Ready to discuss** — able to explain the method, evidence, limitations, and trade-offs clearly.

## Target Skill Areas

As I study and practice, I plan to build evidence in these areas:

- Security operations fundamentals and incident-response lifecycle
- Security alert triage, severity assessment, and escalation
- Log analysis and event correlation
- SIEM concepts and searches (using tools that are available in authorized training environments)
- Network-security fundamentals and packet analysis
- Linux command-line investigations and SQL queries
- Basic Python automation for repetitive analysis tasks
- Clear incident notes, handoffs, and technical reporting

These are development goals, not claims that I have already mastered every skill. Current proficiency and evidence are tracked in the [Skills Matrix](skills-matrix.md).

## Project Documentation Standard

Each report should identify its objective, scope, authorization, environment, method, evidence, findings, limitations, and recommended next steps. I distinguish observed facts from hypotheses and label simulated work clearly.

## Ethics and Data Handling

I use authorized labs, synthetic data, or public datasets permitted for this use. I do not test systems without permission or publish credentials, tokens, personal information, confidential logs, or proprietary material.

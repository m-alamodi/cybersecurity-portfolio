# Official Learning Resources for the SOC Track

Use these as optional follow-on resources after or alongside the relevant course topics. Always check requirements and availability before starting.

- **Google Cybersecurity Certificate overview:** https://www.coursera.org/professional-certificates/google-cybersecurity
  Covers foundational security concepts, Linux, SQL, Python, SIEM tools, IDS, and incident response practice.
- **Microsoft Learn — KQL for Microsoft Sentinel:** https://learn.microsoft.com/en-us/training/paths/sc-200-utilize-kql-for-azure-sentinel/
  Useful later for querying security data in Sentinel; it expects some basic scripting understanding.
- **Splunk free training:** https://www.splunk.com/en_us/training/free-courses/overview.html
  Includes introductory material for searches, fields, and dashboards.

These are learning resources, not proof of completed training. Add a credential or skill to your CV only when you have actually earned or demonstrated it.
